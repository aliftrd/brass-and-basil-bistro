**Brass & Basil: Bistro Rush** is an original, tactile HTML5 Canvas cooking and kitchen service game. Manage overlapping multi-step bistro orders, chop fresh ingredients, sear and bake across dual copper skillets and a stone oven, assemble layered dishes mid-counter, and plate hot orders at the pass before the shift timer runs out — playable with both keyboard (`WASD`/Arrows + `Space`/`E`/`F`) and mouse click-to-route.

## Run it

```sh
node serve.ts
```
